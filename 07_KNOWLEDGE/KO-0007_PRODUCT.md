# KO-0007 — Produto

## Definição Oficial

Produto é uma aplicação especializada construída sobre a Plataforma Operacional de Inteligência Educacional da EduData IA.

Todo produto implementa uma experiência específica para determinado público, reutilizando as capacidades disponibilizadas pelo EIOS e pelo Core Compartilhado.

Produtos não constituem patrimônio científico nem tecnológico. Eles representam a materialização prática desse patrimônio para resolver problemas reais da educação.

---

## Objetivo

Transformar o patrimônio científico e tecnológico da EduData IA em soluções de alto valor para usuários e instituições.

---

## Características

Todo produto deve:

- utilizar o Framework EDI;
- consumir serviços do EIOS;
- reutilizar o Core Compartilhado;
- utilizar o Design System institucional;
- respeitar a arquitetura oficial da plataforma;
- produzir evidências para retroalimentar o ecossistema.

- EduData Academy
- EduData Analytics
