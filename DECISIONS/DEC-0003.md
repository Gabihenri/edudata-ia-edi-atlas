# DEC-0002 — Arquitetura Oficial

## Contexto

Após diversas evoluções arquiteturais, tornou-se necessário definir uma organização permanente para todos os componentes da EduData IA.

---

## Decisão

A arquitetura oficial passa a ser:

```
Framework EDI
        ↓
EIOS
        ↓
Core Compartilhado
        ↓
Produtos
```

Todos os produtos deverão respeitar essa hierarquia.

Nenhum produto poderá implementar inteligência própria fora do EIOS.

O Framework EDI jamais conterá código.

O EIOS jamais conterá metodologia científica.

---

## Consequências

- Arquitetura modular.
- Reutilização de inteligência.
- Escalabilidade.
- Redução de duplicação.
- Evolução independente entre Framework e EIOS.

---

## Status

Aceito.
