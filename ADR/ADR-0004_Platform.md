# ADR-0004

## Decisão

A EduData IA deixa de ser tratada como conjunto de aplicações.

Passa a ser oficialmente uma Plataforma Operacional de Inteligência Educacional.

## Consequências

Todos os produtos passam a compartilhar:

- Framework EDI
- EIOS
- Core Compartilhado

## Status

Aceito.
